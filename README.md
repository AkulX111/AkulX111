ThermaTrace — Intelligent Pharmaceutical Cold-Chain Monitoring

ThermaTrace is an AI-based pharmaceutical transportation and cold-chain risk monitoring system that simulates fleet operations, medicine-container conditions, battery health, delivery routes, and risk assessment through a unified operations dashboard.

Live Demo: [thermatrace-pharma.vercel.app](https://thermatrace-pharma.vercel.app)  
API Health: [thermatrace-api.onrender.com](https://thermatrace-api.onrender.com/api/health)

Key Features

- Fleet Monitoring:** Real-time simulated vehicle telemetry, GPS tracking, delivery progress, and route deviation detection.
- Cold-Chain Monitoring:** Medicine-specific temperature profiles, humidity tracking, excursion duration, and predictive alerts.
- AI-Based Risk Assessment:** Isolation Forest anomaly detection and Random Forest risk prediction with interpretable risk indicators.
- Battery Management:** Monitoring of State of Charge (SOC), State of Health (SOH), voltage, current, and battery temperature.
- Route Tracking:** Interactive maps, vehicle movement, planned routes, estimated arrival times, and delivery status.
- Analytics and Reporting:** Historical telemetry analysis, incident tracking, and downloadable CSV, JSON, and PDF reports.
- Multilingual Voice Assistant:** Operational queries in Hindi, English, and Marathi, with database-grounded responses.
- Access Control:** Role-based permissions for Admin, Operator, and Viewer accounts.

 Technology Stack

Frontend: Next.js, React, TypeScript, Tailwind CSS, Recharts, React-Leaflet  
Backend: Python, FastAPI, Pydantic, SQLAlchemy, WebSockets  
Machine Learning: Scikit-learn, Isolation Forest, Random Forest, NumPy, Pandas  
Database: SQLite, PostgreSQL, Alembic  
Mapping and Integration:** OpenStreetMap, OSRM, MQTT  
Deployment: Vercel, Render, Supabase

 Project Objective

To demonstrate how simulated fleet telemetry, pharmaceutical cold-chain monitoring, anomaly detection, and explainable machine-learning models can support risk-aware pharmaceutical logistics operations.

Project Type: Collaborative Engineering Project

Disclaimer: This project is an educational software simulation using synthetic data. It is not a validated pharmaceutical safety system and does not establish regulatory compliance.
